{{ _('Uninstall Ubuntu') }}
This removes the Ubuntu install from the NVMe drive.
  • The Ubuntu root and swap partitions are deleted, along with everything on them. This cannot be undone.
  • The RAVE2 application images and menu system are kept.
  • The free NVMe space is returned to the same unpartitioned state it was in before Ubuntu was ever installed.
  • Ubuntu is removed from the boot menu; the RAVE2 menu becomes the default boot option again.
